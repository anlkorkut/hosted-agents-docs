# Foundry Hosted Agents

Client architecture brief covering agent operating models, network security, identity, Basic and Standard setups, Hyper-V MicroVMs, deployment, infrastructure as code, and pricing.

**Website:** https://anlkorkut.github.io/hosted-agents-docs/

The site is a self-contained `index.html` with embedded fonts and diagrams. It includes a desktop sidebar, responsive mobile layout, light/dark colors, diagram zoom controls, and print styling.

GitHub Pages publishes the root of the `main` branch. Update `index.html` and push to `main` to publish a revision. No build dependencies are required.

Content and prices are dated October 28, 2026. Technical references are linked in the brief. The Hyper-V architecture description incorporates Foundry product group confirmation.

Embedded IBM Plex Sans and IBM Plex Mono fonts are distributed under the SIL Open Font License. Their license notices are in `licenses/`.
